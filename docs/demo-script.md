# Demo script (5-7 minutes)

1. State the HR problem, confirmed clarifications, and deliberate exclusions from the one-page requirements document.
2. Open the hosted URL, mention the free-service cold start, and sign in as the demo HR manager.
3. Ask “How does ACME pay its people?” and use the overview to show headline metrics, percentiles, and country/department/level/gender comparisons. Apply a filter, point out the shareable URL, and explain fixed FX and why gender figures are descriptive rather than an adjusted pay-gap analysis.
4. Search the 10,000-record directory, open an employee, record a salary change, and show preserved history.
5. Validate one invalid CSV, explain atomic failure, then import a valid row and export active employees.
6. Show the modular-monolith diagram, PostgreSQL model, deterministic seeding, API documentation, and tests.
7. Close with AI verification practices, deliberate exclusions, free-tier risks, production hardening, and likely next capabilities.
